A small C++ project template using Make and Clang++.

* Build

#+begin_src sh
make
#+end_src

The executable is created at =build/program=.

* Run

#+begin_src sh
./build/program 1 2 3
#+end_src

This prints the sum of the provided integer arguments.

* Clean

#+begin_src sh
make clean
#+end_src
