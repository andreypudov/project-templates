A small Python project template using a virtual environment.

* Setup

#+begin_src sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
#+end_src

* Run

#+begin_src sh
python program.py 1 2 3
#+end_src

This prints the sum of the provided integer arguments.

* Clean

#+begin_src sh
deactivate
rm -rf .venv
#+end_src
