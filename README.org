This repository provides small, reusable project templates for getting
started quickly with common development setups.

* Available Templates

| Template        | Description                               |
|-----------------+-------------------------------------------|
| [[file:c-make-basic/README.org][c-make-basic]]    | Basic C project using Make and Clang      |
| [[file:cpp-make-basic/README.org][cpp-make-basic]]  | Basic C++ project using Make and Clang++  |
| [[file:cpp-cmake-basic/README.org][cpp-cmake-basic]] | Basic C++ project using CMake and Clang++ |
| [[file:cpp-cmake-prod/README.org][cpp-cmake-prod]] | Production C++ project using CMake        |

Each template is self-contained and includes the files needed to build and
run a minimal example. Open its setup guide for template-specific steps.
